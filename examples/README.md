# Fictional example data

`demo-profile.json` is a design fixture with invented career records, not a runnable seed or a resume importer. Its collection names follow document 04; the implementation will define and validate the actual seed format. It must never be loaded automatically into an existing personal database.

The fixture covers a measurable employment achievement, a project achievement without an invented metric, a standalone achievement, optional fields, and reusable skill links. Use an isolated demo/test database when a loader exists. The contact address uses the reserved example.com domain.
