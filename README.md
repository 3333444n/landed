# Landed

Get the interview. Landed is a locally run job-search application that turns your real career evidence into tailored resumes, cover letters, and recruiter messages, and tracks every application. It rewrites and reorganizes your facts; it never invents them.

**Status: design stage. There is no runnable application or supported installation command yet.**

The selected stack is TypeScript, Next.js/Node.js, and PostgreSQL. The first milestone is manual profile and achievement entry with durable local storage. Later milestones add tailored resumes, cover letters, recruiter messages, PDFs, matching, research, discovery, and interview tracking.
